State Lifting in React

This project demonstrates the concept of state lifting in React — a fundamental technique for managing shared state across multiple components.

Purpose
State lifting allows child components to communicate and synchronize data by elevating shared state to their common parent. This example showcases how input values from child components can be reflected and controlled via a parent component.

Features
1. Two child input components that update a shared state.

2. Real-time synchronization of input values across components.
